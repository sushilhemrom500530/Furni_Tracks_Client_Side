# 🛋️ Furni Track

**Live Site:** [Furni Track Website](https://book-reader-bd20d.web.app/)

Furni Track is a modern furniture e-commerce platform where users can explore and purchase various furniture items. The application supports different roles—**Admin**, **Manager**, and **Customer (Guest/User)**—each with unique access and dashboard capabilities. It includes full product management, sales summaries, customer interaction tools, and secure payment integrations.

## 🧰 Tech Stack

### 🔧 Frontend
- **React 18**
- **Vite**
- **Tailwind CSS** with **DaisyUI**
- **React Router DOM v6**
- **React Hook Form** for form management
- **AOS** for scroll animations
- **Stripe** for payment integration
- **Firebase** for authentication and hosting
- **React Query** for efficient data fetching and caching
- **Swiper.js** for sliders
- **Recharts & ApexCharts** for analytics

### 📦 Additional Libraries
- Axios
- Lottie React
- SweetAlert2
- React Icons
- React Rating Stars
- Google Map React
- React Messenger Chat
- LocalForage (for local storage)
- Inner Image Zoom
- React Loader Spinner
